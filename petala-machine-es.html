Como ajustar engrenagens, braços e caneta

Clique em uma peça para selecioná-la e use as setas do teclado ou os botões abaixo. Arraste os pontos de fixação para movê-los. Use Shift + setas para alterar os dentes um a um. Clique na máquina para ativar os atalhos.

Espaço: desenhar/pausar · 0–9: velocidade · A–G: montagens · X: limpar · [ e ]: cor · < e >: espessura · /: inverter braço · ~: completar ciclo.

O SVG contém os traços feitos dentro do papel, com as cores escolhidas. O ciclo pode ter muitas voltas. Pause quando gostar do resultado; a exportação usa o desenho atual.

Ajustar peça selecionada:A máquina mantém as dimensões originais. Role a área para ver todas as peças.
